# দৈনিক আদিবাসী

A standalone Bengali newspaper-style page for a family ghost story. Characters, quotations and incidents are creative storytelling, not verified reporting. The page intentionally has no visible fiction label at the author's request. Please clarify the story's fictional nature to children after reading.

## Use
Open index.html in any modern browser. All styling and the illustration are included; no installation, external fonts, tracking or dependencies are needed.

## GitHub Pages
Upload index.html and .nojekyll to the root of your GitHub repository. In the repository's Pages settings, choose deployment from the main branch and /(root), then save. Follow the published URL shown by GitHub after deployment. If using another branch, select that branch instead.

The HTML includes noindex/nofollow/noarchive as a request to search engines; this does not restrict public access. To remove the published story, disable Pages or remove the page and redeploy.

Print with the button at the bottom or your browser's Print command. The layout adapts to mobile screens.
